📊 Market Basket Analysis Dashboard & Recommendation Engine
🔎 Project Overview

This project focuses on analyzing retail transaction data to identify product purchase patterns and build a basic recommendation engine using association rule mining techniques.

🎯 Business Objective

Retail businesses often need to understand which products are frequently purchased together in order to improve cross-selling strategies, product placement and promotional offers.

🗂 Dataset

Retail transactional dataset containing invoice details, product descriptions, quantities and customer IDs.

🧹 Data Cleaning

Removed cancelled invoices

Removed negative quantities

Handled missing product descriptions and customer IDs

Converted invoice date into datetime format

Created basket matrix for product association analysis

🤖 Algorithm Used

Apriori Algorithm was applied to generate frequent itemsets and association rules.

📈 Metrics Used

Support → Frequency of product combination

Confidence → Reliability of recommendation

Lift → Strength of association beyond random chance

📊 Dashboard Pages

Basket Overview — KPI summary and frequently purchased products

Association Rule Intelligence — Rule strength distribution and bundle opportunity analysis

Recommendation Engine — Dynamic product recommendations using slicer-based interaction

💡 Key Insights

A small number of products dominate purchase frequency

Some bundles show very strong association strength

Many rules show moderate confidence indicating potential cross-selling opportunities

💼 Business Value

Improves product bundling strategy

Helps design targeted promotions

Optimizes store layout

Enhances recommendation systems

Increases average basket value
